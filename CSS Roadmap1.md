# 💡 Important Learning Tips

আমার পক্ষ থেকে কিছু গুরুত্বপূর্ণ পরামর্শ:

1. কোনো CSS Property মুখস্থ করবে না; কীভাবে এবং কেন কাজ করে বুঝবে।
2. Tutorial দেখে সরাসরি Code Copy করবে না। প্রথমে বুঝবে, তারপর নিজে লিখবে।
3. Flexbox, Grid, Position এবং Responsive Design-এ বেশি গুরুত্ব দেবে।
4. প্রতিটি Phase শেষ করার পর অন্তত একটি Project তৈরি করবে।
5. CSS শেখার সময় Tailwind CSS-এর ওপর নির্ভর করবে না। প্রথমে Vanilla CSS দিয়ে Design তৈরি করতে শিখবে।
6. MDN Documentation পড়ার অভ্যাস তৈরি করবে।
7. প্রতিটি Project GitHub-এ Upload করবে।
